# O-CUT — AI Music & Video Studio

**0.17.0 후보**: 생성곡 체크박스·전체 구간 허밍/보이스 로컬 검사·구간 듣기·선택 검출곡 완전 삭제와 영상 오디오 분리를 추가했습니다. 설치본 반영 여부는 `UPDATE_REPORT.md`의 현재 검증 기록을 확인하세요. CapCut 전체 기능 동등성은 확인하지 않았습니다.

음악 생성부터 영상 편집·자막·시각화·출력으로 이어지는 독립 데스크톱 제작 도구를 개발하는 저장소입니다.

이전 0.14.2 출고 기록: 바탕화면 또는 시작 메뉴의 **O-CUT**에서 로컬 AI 음악 생성 → 타임라인 → 볼륨·페이드 → 영상·텍스트·자동 자막·시각화 → MP4 내보내기로 작업합니다. **시각화 → 음악 영상 프로젝트 만들기**로 음악 한 곡에서 편집 가능한 기본 영상을 구성합니다. 위치·크기·회전·불투명도·볼륨 키프레임, 색 보정과 여섯 가지 전환을 편집합니다. 상단 기능 탭과 3열 음악 작성·4영역 영상 편집·3영역 집중 배치를 지원합니다. 필터·그레인·노이즈·비네트 및 자체 장식 4종을 편집할 수 있습니다. 자동 저장과 최근 프로젝트·복구 목록을 지원합니다. 음악은 최대 7분, 16개 장르 자동 스타일 프롬프트, 기본 10곡 일괄 순차 생성·일시 정지·재개를 지원합니다. 개발용 `dist/studio`를 직접 실행할 때는 폴더 전체를 유지해야 하며, 자동 업데이트는 설치된 앱에서 동작합니다.

2026-10-09: 설치된 앱 0.14.0 → 0.14.1 자동 업데이트 적용과 실제 사용자 데이터 재실행을 확인했다. 설치 파일 86개와 기존 사용자 자료 22개 해시가 일치한다. 설치 앱의 음악 폴더 버튼과 완료된 곡 폴더 버튼도 실제 OS shell 호출에서 오류 없이 반환됐다. 133/133 검사·Studio 23단계 PASS. 음악 단계별 진행률·저장 폴더 열기, Ctrl+휠·전체 보기로 10시간 타임라인 탐색, 경계선 드래그로 패널 크기 조절을 지원한다. 기존 Windows 등록·시작 메뉴를 보존하므로 신규 등록/제거 2개 시나리오는 NOT RUN, 전체 설치 Gate BLOCKED. 별도 로컬 업데이트 Gate는 PASS. [검증과 복구 기록](PROGRESS_NAVIGATION_REPORT.md).

AI 음악은 기존 Python·YuE2 모델과 NVIDIA CUDA GPU, 자동 자막은 로컬 Whisper 모델과 Transformers를 사용하며 자동 다운로드/설치는 없습니다. 자막은 GPU 자동 선택과 CPU 모드를 지원하고 글꼴·색·배경·그림자 및 네 가지 프리셋을 편집합니다. 음악 생성 고급 기능(MIDI/ABC), GPU 출력, 최신 런타임 갱신은 후속 개발 항목입니다. 시각화 분석은 10분 이하 소스, 음성 인식은 30분 이하 클립으로 제한합니다.
