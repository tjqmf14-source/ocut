# O-CUT — AI Music & Video Studio

음악 생성부터 영상 편집·자막·시각화·출력으로 이어지는 독립 데스크톱 제작 도구를 개발하는 저장소입니다.

현재 **O-CUT 0.14.0 개발 빌드**를 사용할 수 있습니다. 바탕화면 또는 시작 메뉴의 **O-CUT**에서 로컬 AI 음악 생성 → 타임라인 → 볼륨·페이드 → 영상·텍스트·자동 자막·시각화 → MP4 내보내기로 작업합니다. **시각화 → 음악 영상 프로젝트 만들기**로 음악 한 곡에서 편집 가능한 기본 영상을 구성합니다. 위치·크기·회전·불투명도·볼륨 키프레임, 색 보정과 여섯 가지 전환을 편집합니다. 상단 기능 탭과 3열 음악 작성·4영역 영상 편집·3영역 집중 배치를 지원합니다. 필터·그레인·노이즈·비네트 및 자체 장식 4종을 편집할 수 있습니다. 자동 저장과 최근 프로젝트·복구 목록을 지원합니다. 음악은 최대 7분, 16개 장르 자동 스타일 프롬프트, 기본 10곡 일괄 순차 생성·일시 정지·재개를 지원합니다. 개발용 `dist/studio`를 직접 실행할 때는 폴더 전체를 유지해야 하며, 자동 업데이트는 설치된 앱에서 동작합니다.

2026-10-06: 설치된 앱 0.13.0→0.14.0 자동 업데이트 적용 완료. 실제 사용자 데이터로 재실행해 9개 도구 탭·항상 보이는 가사창·연주곡 체크·16개 장르·7분·기본 10곡을 확인했다. 설치 파일 86개와 기존 사용자 자료 11개 해시가 일치한다. Studio 21단계·128/128 검사, 3가지 화면 배치와 질감/장식 MP4, 실제 7분·10곡·한국어 가사 전달 생성 및 업데이트 6개 흐름을 확인했습니다. 기존 Windows 등록·시작 메뉴를 보존하므로 신규 등록/제거 2개 시나리오는 NOT RUN, 전체 설치 Gate BLOCKED. 별도의 실제 로컬 업데이트 Gate는 PASS. [화면·로파이 도구 보고서](WORKSPACE_EDITOR_REPORT.md), [자동 업데이트 기록](UPDATE_REPORT.md), [설치 검증](RELEASE_REPORT.md)을 참고하세요.

AI 음악은 기존 Python·YuE2 모델과 NVIDIA CUDA GPU, 자동 자막은 로컬 Whisper 모델과 Transformers를 사용하며 자동 다운로드/설치는 없습니다. 자막은 GPU 자동 선택과 CPU 모드를 지원하고 글꼴·색·배경·그림자 및 네 가지 프리셋을 편집합니다. 음악 생성 고급 기능(MIDI/ABC), GPU 출력, 최신 런타임 갱신은 후속 개발 항목입니다. 시각화 분석은 10분 이하 소스, 음성 인식은 30분 이하 클립으로 제한합니다.
